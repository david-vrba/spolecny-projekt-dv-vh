## Image processing pipeline

All images must be:
- Downloaded locally (no hot-linking — performance + reliability)
- Converted to optimized format (see `technical-notes.md` re: AVIF research)
- Resized to actual rendering dimensions (no oversized images)
- Given meaningful filenames (e.g., `barbican-london.avif`, not `image-1.jpg`)
- Each `<img>` gets a Czech-language `alt` describing what's shown
